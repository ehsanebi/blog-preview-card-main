## Overview

This project is a responsive blog preview card built as part of a Frontend Mentor challenge.

### The challenge

The main challenge was finding a way to reduce font sizes on smaller screens **without using media queries**.

Users should be able to:

- View hover and focus states for all interactive elements on the page

### What I learned

In this project, I learned how to create a responsive layout using the `clamp()` function.  
It helped me adjust font sizes smoothly across different screen sizes without relying on media queries.  
I found this approach cleaner and more flexible than the methods I used before.

### Continued development

I want to continue using `rem` units and the `clamp()` function in future projects.  
Before this challenge, I mostly relied on `px` values and media queries, so this was a great learning experience for me.
